- Sidebar navigation with smooth scroll

- Education timeline

- Responsive design

## Technologies Used

- HTML5

- JavaScript

## Run Locally

Open the `portfolio/index.html` file in your browser.

Or run a local server in the project folder:

```bash
cd /Users/aungkaungsett/ipython/portfolio
python3 -m http.server 8000
```

Then open:

```text
http://localhost:8000
```
